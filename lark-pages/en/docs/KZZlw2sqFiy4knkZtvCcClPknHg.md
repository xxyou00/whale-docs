# Message Settings

Message Settings is a proprietary Whale Back Office (WBO) system feature that enables brokerage operators to configure and send specific message notifications for the scenarios below, facilitating real-time message notification management.

Scenario 1: To-Do Notifications (Workflow/Task-Based)

1. Notifications for specific approval stages or workflow nodes. These messages can be directed to a specific WBO operator or any operator with the required permissions.
2. Task reminders.

Scenario 2: System Notifications (SaaS Providers)

1. Announcements for system maintenance, upgrades, and new feature releases.
2. Notices regarding secure system logins.
3. Notices related to certain brokerage business operations.

Scenario 3: System Operational Notifications (Securities)

1. Example: Exchange rate import reminders.
2. Example: Manual settlement reminders.
3. Example: Report generation reminders.

# Subscription Management

Operators can access this feature by clicking the settings icon next to their avatar.

<img src="/assets/QjIBbPYokom3BrxsJXVjFEC6p6b.png" src-width="3702" src-height="316" align="center"/>

Navigation: <em>Global Settings</em> &gt; <em>Messages</em> &gt; <em>Subscription</em>

- This feature is primarily used to manage message subscriptions for system operators.

<img src="/assets/Vr4rbQlQmoWogYx4R3LjcBZipMg.png" src-width="3786" src-height="1760" align="center"/>

To set up a new message subscription, click <em>New</em>.

<img src="/assets/UciVbpnbroayLlxIggojSngNpFe.png" src-width="3294" src-height="1200" align="center"/>

Operators can configure message receiving channels according to the message types provided by the system. The system currently supports email notifications and Webhook. Operators can select system operators or system roles as message recipients.

<img src="/assets/DNoMb2qJKoRyFext30lj3Fy9pkg.png" src-width="1032" src-height="896" align="center"/>

Once a message subscription is configured, notifications will be delivered via the configured channels.

- System Update (January 30): To provide more message notifications, the following types of business alert messages have been added to the system:
    - Daily successful execution of accounting entries.
    - Bank statement balance reconciliation.
    - Successful entry rerun results.
    - Failed entry rerun tasks.

- System Update (April 10): The "New Customer Bank Card Alert" and "New Customer Bank Card Approval Alert" have been added and can be configured as needed.

<img src="/assets/LYA7bmR2QoPxv0xCnp8jKQLopch.png" src-width="1032" src-height="896" align="center"/>

When an alert is activated, the relevant personnel will receive an email notification.
