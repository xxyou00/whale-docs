# Task Interface

# Assignment Interface

Whale provides optimized experience for managing assignments and tasks. Below are the common design patterns and interactions an operator will encounter on the platform.

<b>Batch Actions: On certain pages, batch action buttons will automatically appear once an operator selects one or more records</b>

No records currently selected.

<img src="/assets/EQmbbshy4obg8dxbGskjKbuqppf.png" src-width="3286" src-height="1714" align="center"/>

After selection, applicable action buttons will automatically appear.

<img src="/assets/SZfcb2qZOoCUOZxbTxtjMTUMpAe.png" src-width="3246" src-height="1788" align="center"/>

<b>Row-Level Details: In some task tables, operators can click anywhere on a record row to open a detailed view in a side panel (sliding out from the right)</b>

<img src="/assets/JcHwbI02ZoqPmsxFyeZjQqjYpId.png" src-width="3250" src-height="1696" align="center"/>

Record details slide out from the right.

<img src="/assets/EgNUbgVZUoRk7IxqNTXjJGpfpxh.png" src-width="3282" src-height="1808" align="center"/>

<b>Sticky Horizontal Scrollbar: For some tables with many columns, a horizontal scrollbar is anchored to the bottom</b>

Operators can use the horizontal scrollbar at the bottom to view records from the left to the right.

<img src="/assets/NodIbg6eco8Y3lx6EeBjbp69pHb.png" src-width="2612" src-height="1464" align="center"/>

<b>Sticky Table Headers: On some pages, table headers can be fixed at the top of the page as operators scroll through long lists of records</b>

# General Component Instructions

- <b>Input Field Hints</b>
    <img src="/assets/Z71vbZbwBoukOvx4v5GjFIX2pdc.png" src-width="700" src-height="62" align="center"/>
    - Some fields include specific placeholder text to provide guidance on the required information.

- <b>Date Fields</b>
    <img src="/assets/InOjbpNA2oWub1xtZmVjC4k5pdb.png" src-width="1098" src-height="500" align="center"/>
    - Click a date field to open a calendar interface for quick date selection.

- <b>Dropdown Lists</b>
    <img src="/assets/ZArJbP8mOoqPqMxFQfxjg91JpGg.png" src-width="1140" src-height="142" align="center"/>
    <img src="/assets/Tw5IbnwB4oYh7AxyD02jM2jKpff.png" src-width="1134" src-height="654" align="center"/>
    - Click the arrow icon in a selection field to view and select from a list of predefined options.

- <b>Client Search Fields</b>
    <img src="/assets/A7RSbn2otoQk5hxS6KjjeBcfpCh.png" src-width="1138" src-height="528" align="center"/>
    - The system provides multiple fields to facilitate locating and querying the corresponding client.

- <b>Advanced Search</b>
    <img src="/assets/SDoRb3fdhoi7AYxPh54jGz6fpDc.png" src-width="322" src-height="100" align="center"/>
        <img src="/assets/AkdmbFRihoxfibxNl0kjuM3opoe.png" src-width="306" src-height="88" align="center"/>
    - In the search criteria area, click this button to expand or collapse additional filters.

- <b>Fields Supporting Search</b>
    <img src="/assets/CPX5biDmmohVvfxRywQjK1Zsptg.png" src-width="592" src-height="184" align="center"/>
        <img src="/assets/EBJhb3k3DoODlQxg09MjL4SApWd.png" src-width="556" src-height="656" align="center"/>
    - If the placeholder in the field box contains the word "Search", it indicates that the field supports fuzzy search.

- <b>Table/List Pagination</b>
    <img src="/assets/KcmUbX6CBo3i6lxyWHpjaQAbpNb.png" src-width="1050" src-height="118" align="center"/>
    - Operators can configure the number of displayed per page and navigate to a specific page.

- <b>Export Search Results</b>
    <img src="/assets/NEkebqyjooV0XGx3S4qjPG6Qpkc.png" src-width="1894" src-height="344" align="center"/>
    - Operators can export and download their search results.

- <b>Mandatory Field Indicator</b>
    <img src="/assets/USfoboPADoqkXxxX5OkjkaDzpbb.png" src-width="794" src-height="230" align="center"/>
    - A red asterisk (*) before a field name indicates that the information is mandatory.

- <b>Add/Remove Controls</b>
    <img src="/assets/CHytbVBfioX7skxuZkWjotKKp7e.png" src-width="1256" src-height="276" align="center"/>
    - Use the + or – icon to add or delete data groups.

- <b>Search and Clear Icons</b>
    <img src="/assets/ZEAPbONEqo7kpax0Qlzjkc27phb.png" src-width="294" src-height="164" align="center"/>
    - Operators can use the search icon to apply filters and the clear icon to clear the search criteria.

- <b>Export Data</b>
    <img src="/assets/ToAnbqN1Ho3yQsxPNnKj5rHnpEe.png" src-width="1894" src-height="344" align="center"/>
    - Operators can click the export icon to export list records to Excel/CSV formats.

- <b>Field Tips</b>
    <img src="/assets/QdBkbEelhoXb75xwkkhjapwapSe.png" src-width="754" src-height="322" align="center"/>
    - Hover over or click the "i" icon next to a field to view additional explanatory text.

- <b>More Actions</b>
    <img src="/assets/RXc7bMu30oif7jxiKqYjSrAKp4f.png" src-width="791" src-height="219" align="center"/>
    - Click the "..." icon to access additional actions.

- <b>Customizable Columns</b>
    <img src="/assets/Fxdob1mb9oT238xoC9XjWTewpSf.png" src-width="3256" src-height="1758" align="center"/>
    - Operators can click the settings icon to select which columns are displayed in the list.

- <b>New Feature Tips</b>
    - When a new feature is released, a one-time interaction prompt will be displayed to guide operators through the update.
