# Global Search

Whale's Global Search feature offers two tabs: <em>Menu</em> and <em>Client</em>

<img src="/assets/WlYBbMD5OoTuLnxobYzjAyUJpxg.png" src-width="3112" src-height="758" align="center"/>

After logging in, operators can access the search interface by clicking the search icon in the upper-right corner or by using keyboard shortcuts. 

<img src="/assets/X43nbcBNrovWQCx1iI2jiHLPp5f.png" src-width="3810" src-height="130" align="center"/>

## Global Function Search

The <em>Menu</em> tab allows operators to enter relevant keywords to quickly find job functions, facilitating seamless navigation to the desired job.

## Global Client Search

The <em>Client</em> tab allows operators to search client information by different fields.

<img src="/assets/Owt4bOk23oj3bNxvb3Ajfrf5pih.png" src-width="2570" src-height="1428" align="center"/>

Once a client is identified, the system displays a brief summary of the client's basic information and contact details. The search supports:

- Fuzzy search by client name or securities account number.
- Name search by the client's English name, with English name displayed in results.

<img src="/assets/EyVYbCcUCoD5T8xnJpfjeSpSprc.png" src-width="2608" src-height="1460" align="center"/>

<em>Client Detail</em> panel: After an operator selects a client record, a panel slides in from the right, showing a client summary and key asset and transaction information.

<img src="/assets/QfRdbvD0ooa8cDxyT7ujr8FKp9c.png" src-width="3800" src-height="1758" align="center"/>

<b>Assets Overview</b><b> tab</b>: Operators can switch between different asset currencies to view the total asset values. An asset data dashboard is available in the top-right area of this tab.

The lower sections display the client's risk status and a financing summary..

<b>Cash Detail</b>: displays available cash and pending settlements categorized by currency.

<b>Holdings Details</b>: displays holdings records for stocks, options, funds, and other instruments.

<img src="/assets/LwC9bbLDhoscvwxu8IfjdZp0pg5.png" src-width="3822" src-height="1914" align="center"/>

<img src="/assets/NjrgbiqcxoVBNmx6r9Ij28g9pcf.png" src-width="1584" src-height="1834" align="center"/>

<b>Deposit/Withdrawal</b><b> tab</b>: Operators can view the client's deposit and withdrawal records and directly edit them.

<img src="/assets/ZgFFbELvrom29YxqcqHjbt8opMP.png" src-width="1540" src-height="1616" align="center"/>

<b>Bank Card tab</b>: Operators can view the client's bank card information and directly edit it.

<img src="/assets/TccObNWE4ojEgoxAXbTjQEKApCf.png" src-width="1578" src-height="1290" align="center"/>

<b>Billing tab</b>: Operators can view the fee items related to the client's account.

<img src="/assets/Rh5kbUxNAoqYr6xo438jbtCcpog.png" src-width="1550" src-height="1182" align="center"/>
