# Frequently Asked Questions

# FAQs

<div class="callout callout-bg-5 callout-border-5 callout-color-1">
<div class='callout-emoji'>📍</div>
<p>Q: If I forget to set the broker notification status to Informed when submitting an application, what should I do?</p>
</div>

A: On the transfer-out application page, click Edit in the Action column, and check Informed in the pop-up window.

Go to Transfer Out &gt; Transfer Out and click Edit.

<div class="callout callout-bg-5 callout-border-5 callout-color-1">
<div class='callout-emoji'>📍</div>
<p>Q: What is the difference between the Reject on the transfer-out application page and the Delete on the transfer-out details page?</p>
</div>

A: The applicable scenarios are different. Click Reject when the application contains an error, for example, incorrect account information. Click Delete when the application does not contain any error, but a specific detail record does not need to be processed for transfer-out.
